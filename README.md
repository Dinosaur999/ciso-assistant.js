# CISO Study Helper

A lightweight, local-only browser study aid for cybersecurity,
networking, computer science, and IT concepts.

## Files

- `ciso-assistant.js`: Hyperweb-compatible userscript.
- `README.md`: Project documentation.

## Setup

1. Open the public GitHub repository.
2. Open `ciso-assistant.js` and select Raw.
3. Copy the raw file URL.
4. In Hyperweb, open Popular > Custom Scripts.
5. Add the script URL and enable it.
6. Visit a website allowed by the script's `@match` rule.

## Features

- Floating study helper panel.
- Local keyword-based concept explanations.
- Short exam tips.
- No AI API key or external AI service required.

## Limitations

This is a basic rule-based study aid, not an AI system.
It may fail to recognize concepts and does not guarantee
the correct answer to a multiple-choice question.

## Security

Review the source before running it. The repository is public.
Do not include credentials, secrets, or private study material.
